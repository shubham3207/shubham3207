## 🤝 How I Work

> 🎯 **Start with the decision.** I ask what choice the analysis will inform before I write any code.
>
> 🧭 **Make it self-serve.** The best dashboard is one people open without needing my help.
>
> ⚙️ **Automate the repeatable.** If I do something twice, I'm already scripting it.
>
> 🗣️ **Explain it simply.** An insight the whole room can't understand isn't finished yet.
